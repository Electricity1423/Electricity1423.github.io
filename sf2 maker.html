🎹 Easy SoundFont Maker

Create a SoundFont (SF2) with one or many instruments from audio samples (WAV, MP3, OGG, FLAC, etc.), or import an SFZ instrument.

1. Name your SoundFont

Every instrument you create in step 2 becomes its own preset in the SF2, with the MIDI program number you give it.

2. Instruments and samples

Auto-detect reads a note name from the file name first (like Piano_C4.wav or pad-f#3.wav), then estimates the pitch from the audio. You can fix any root note by hand in the list below.

“One instrument per file” lets you pick many files at once. Each file becomes its own instrument (named after the file) with its own program number.

3. Import an SFZ instrument (optional)

After loading an SFZ file, select its referenced sample files using the picker below. They are added as a new instrument named after the SFZ file.

No SFZ loaded.

4. Export

Creates a standard RIFF SoundFont 2 (.sf2) with embedded PCM samples and one preset per instrument.

The chosen instrument is written into every program number (0–127), so it plays no matter which program a channel selects. Other instruments are left out of the file. Channel 10 normally looks in the drum bank, so leave the box ticked if you want it to play there too.

Off by default (standard SoundFont pitching, where speed changes with pitch). When on, the page builds a separate pitch-shifted copy of your sample for every key, each with the original length. Keys outside the range above fall back to normal SoundFont pitching. Notes far from the original sample sound best when you add several samples at different pitches, since each key is made from the nearest one.
